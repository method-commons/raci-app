# RACI-Matrix

Responsive Web-App, die beim **methodischen Arbeiten mit der RACI-Methode** hilft: Aufgaben und Rollen sammeln, je Aufgabe festlegen, wer ausführt (**R**esponsible), wer entscheidet (**A**ccountable), wer gefragt (**C**onsulted) und wer informiert wird (**I**nformed) – und die Matrix waagerecht und senkrecht prüfen (genau ein A je Aufgabe, mindestens ein R, Engpässe je Rolle).

Bewusst **kein Aufgaben- oder Projektmanagement**: keine Termine, kein Erledigt-Status, keine Erinnerungen.

Geplant wie die Schwester-Apps [5 Warum](https://github.com/method-commons/5-why-app), [2-Achsen-Matrix](https://github.com/method-commons/two-axis-matrix-app), [User Stories](https://github.com/method-commons/user-story-app) und [Morphologische Matrix](https://github.com/method-commons/morphological-matrix-app): im Browser ohne Server-Backend, Daten im localStorage, Preact mit Signals, gebaut mit Vite, veröffentlicht über GitHub Pages.
